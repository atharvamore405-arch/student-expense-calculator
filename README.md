# Student Expense Calculator / Tracker

A web-based Student Expense Tracker application built with HTML, CSS, and JavaScript.

## Features
- **Add Expense**: Enter expense name, amount (in ₹), and category.
- **Categories**: Food, Travel, Shopping, Education, Other.
- **Filter Expenses**: Filter expenses by category or view all.
- **Total Calculation**: Automatically computes total expenditure.
- **Delete Expense**: Remove specific expense items.

## Technologies Used
- HTML5
- CSS3
- JavaScript (DOM manipulation)
